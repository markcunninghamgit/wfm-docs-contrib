# Warframe.market API v1

The Warframe.market HTTP API v1 provides account authentication used by integrations during the transition to API v2. The v1 sign-in token can be sent as a bearer token to authenticated v2 endpoints.

## API areas

This section documents v1 authentication, HTTP contracts, and statistics. See the [HTTP API overview](./api/overview), [Authentication](./api/authentication), [Contracts](./api/contracts), and [Statistics](./api/statistics) pages.

OAuth 2.0 authorization is not currently available for public integrations. Use v1 sign-in to obtain a bearer token for supported authenticated v2 operations.
